# Раздача индекса владельцев карт Senkuro

Здесь нет кода — только автоматически собираемые данные.

В релизе с тегом `latest` лежит обратный индекс «карта → кто ей владеет»,
которым пользуется приложение [Senkuro Farm](https://github.com/tranthangmu/SenkuroFarm).
Он обновляется ежедневно.

## Формат

| Файл | Что внутри |
|---|---|
| `meta.json` | дата сборки, число игроков и связей |
| `catalog.json.gz` | `slug` карты → её числовой id |
| `users.json.gz` | массив игроков; позиция в массиве и есть порядковый номер |
| `bucket_NNNN.json.gz` | владельцы карт, по 256 карт в файле |

Карты разложены по бакетам, чтобы приложение качало не весь индекс, а один
файл на запрошенную карту: `номер бакета = id карты / 256`.

Внутри бакета игроки адресуются порядковыми номерами из `users.json.gz`,
а не настоящими id — на миллионах связей это определяет размер выгрузки.

```jsonc
{
  "cards": {
    "17129": {
      "o": [12, 480, 5301],   // владельцы карты
      "s": [77],              // владельцы осколка
      "d": [480]              // у кого есть дубликат
    }
  }
}
```

## Оговорка

Проект неофициальный и не связан с администрацией Senkuro. Индекс построен
только из данных, которые сайт отдаёт публично и без авторизации.
